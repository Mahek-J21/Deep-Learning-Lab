## About

This repository contains the Python programs implemented as part of the Deep Learning Laboratory.

## Experiments

1. Word Embedding Generation using Word2Vec
2. Deep Neural Network for Classification
3. Convolutional Neural Network (CNN) for Image Classification
4. Autoencoder for Image Compression
5. Deep Learning Network for Text Classification
6. Time Series Forecasting using LSTM
7. Image Classification using Pre-trained Models (MobileNetV2)
8. Sentiment Analysis of Text Reviews (Positive or Negative)
